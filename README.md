# Java Programs

This repository contains basic Java programs created for learning and practicing Java programming concepts.

## Programs Included

| No. | Program | Description |
|-----|---------|-------------|
| 1 | Hello World | Prints a simple Hello World message |
| 2 | Profit or Loss | Calculates profit or loss using cost price and selling price |
| 3 | Odd or Even | Checks whether a number is odd or even |
| 4 | Voting Eligibility | Checks whether a person is eligible for voting based on age |
| 5 | Anagram | Checks whether two words are anagrams |

## Technologies Used

- Java
- Java Scanner
- Java Arrays

## How to Run

1. Install Java JDK.
2. Clone this repository.
3. Open the project in VS Code, IntelliJ IDEA, or any Java IDE.
4. Compile and run the required `.java` file.

Example:

```bash
javac 01_HelloWorld.java
java HelloWorld
